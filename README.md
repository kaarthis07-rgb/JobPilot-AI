# JobPilot-AI

JobPilot-AI is an AI-powered application designed to help students and job seekers optimize resumes, analyze skill gaps, prepare for interviews, and match with relevant job opportunities using Machine Learning and Natural Language Processing.

## Key Features
- **Resume Optimization & ATS Parser:** Analyzes resume formatting, content, and section completeness.
- **Skill Gap Analysis:** Highlights missing technical and soft skills for targeted roles.
- **Interview Preparation:** Generates dynamic, role-specific technical and behavioral practice questions.
- **Job Matching:** Calculates similarity scores between user profiles and job descriptions using NLP models.

## Project Structure
- `backend/`: API services, NLP models, resume parsing logic, and matching algorithms.
- `desktop/`: User interface and app screens (`main.py`, `dashboard.py`, `login.py`, `jobs.py`, etc.).
